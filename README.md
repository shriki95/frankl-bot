# Frankl Bot

בוט טלגרם פרטי שמשוחח בדמות ויקטור פרנקל, זוכר את מי שמדבר איתו לאורך זמן, ופונה ביוזמתו.

## איך זה עובד

**שיחה** - כל הודעה נשמרת במסד הנתונים. אחרי שתי שניות של שקט (כדי לענות על כמה הודעות קצרות ברצף ביחד), Claude מקבל:
1. את הדמות של פרנקל (`prompts.py`)
2. את **מסמך הזיכרון** על המשתמש
3. את ההודעות האחרונות, מילה במילה
4. הקשר עדכני: התאריך והשעה בישראל, תאריך עברי וחגים, כמה זמן עבר מאז ההודעה הקודמת, והגדרות הפניות היזומות

**זיכרון** (`memory.py`) - כל כ-6 חילופי דברים, ואחרי כל הפסקה של חצי שעה, Claude מעדכן מסמך זיכרון אחד ומסודר: היכרות, אנשים, עבודה, יעדים, חוטים פתוחים, דפוסים, מה עוזר בשיחה, ויומן שיחות. המסמך מתעדכן ולא רק גדל, כך שהבוט לא צריך לקרוא את כל ההיסטוריה בכל הודעה. פרטים ישנים נשארים בטבלת ההודעות, ופרנקל יכול לחפש בהם כשצריך. 30 הגרסאות האחרונות של המסמך נשמרות בטבלה `memory_versions`.

**פניות יזומות** (`reminders.py`):
- **הודעה יומית** בשעה קבועה. ברירת המחדל היא 08:00, ופרנקל שואל בשיחה מה מתאים.
- **פניות מזדמנות**: פרנקל מתזמן מעקב אחרי משהו שעלה בשיחה, למשל "איך היה הראיון?".
- **תזכורות שהמשתמש ביקש**, למשל "תזכיר לי מחר ב-5...".

אם המשתמש כותב באותו רגע, הפנייה נדחית. אחרי שתי הודעות יזומות שלא נענו, פרנקל מפסיק לפנות. פרנקל לא פונה ביוזמתו בין 22:30 ל-07:30. הבוט בודק כל דקה בעצמו אם יש הודעה שהגיע זמנה.

## קבצים

| קובץ | תפקיד |
|---|---|
| `bot.py` | טלגרם, שרת ה-webhook, ולולאות הרקע |
| `brain.py` | בניית ההקשר, השיחה עם Claude והכלים |
| `memory.py` | שמירת הודעות, מסמך הזיכרון והחיפוש |
| `reminders.py` | הודעה יומית, פניות מזדמנות ותזכורות |
| `clock.py` | זמן אמיתי בישראל ותאריך עברי |
| `prompts.py` | כל הטקסטים: הדמות, הנחיות הזיכרון וההודעות הקבועות |
| `db.py` | חיבור ל-PostgreSQL והסכמה |
| `llm.py` | הלקוח של Claude |

## משתני סביבה

| משתנה | חובה | הסבר |
|---|---|---|
| `TELEGRAM_TOKEN` | כן | הטוקן של הבוט |
| `ANTHROPIC_API_KEY` | כן | מפתח ה-API של Claude |
| `DATABASE_URL` | כן | כתובת PostgreSQL |
| `WEBHOOK_SECRET` | מומלץ | סוד ארוך ואקראי. בלעדיו נוצר סוד אקראי בכל הפעלה, והבוט עובד רגיל, אבל אי אפשר לקרוא ל-`/tick` מבחוץ |
| `PUBLIC_URL` | לא | הכתובת הציבורית. ב-Render וב-Railway היא מזוהה אוטומטית |
| `MODEL` | לא | ברירת מחדל: `claude-sonnet-5-5` |
| `MEMORY_MODEL` | לא | המודל שמעדכן את הזיכרון. ברירת המחדל: זהה ל-`MODEL` |
| `CHAT_EFFORT` | לא | עומק החשיבה בשיחה: `low` (ברירת מחדל), `medium` או `high` |
| `DEFAULT_DAILY_TIME` | לא | שעת ההודעה היומית למשתמש חדש. ברירת המחדל: `08:00` |
| `ALLOWED_USER_ID` | לא | מזהה הטלגרם של המשתמש היחיד שמורשה לדבר עם הבוט |
| `KEEP_AWAKE` | לא | `1` שולח בקשה עצמית כל 10 דקות, כדי שהשרת ב-Render החינמי לא יירדם ויפספס הודעות מתוזמנות. ב-Render הוא פעיל אוטומטית |

## כתובות

- `POST /webhook` - עדכונים מטלגרם. מאומת בכותרת סודית שטלגרם שולח.
- `GET /tick?secret=...` - הפעלה חיצונית של בדיקת התזכורות. אופציונלי, כי הבוט בודק לבד כל דקה.
- `GET /morning` - נשאר רק כדי ש-cron ישן לא ייכשל. הכתובת רק מעירה את השרת.
- `GET /health` - בדיקת חיים.
